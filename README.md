# 新見という土地

岡山県新見市を紹介する、個人の趣味サイト。

友人が新見にいて、三年間、毎年通っている。記者でも研究者でも、市の関係者でもない。
調べたことと、自分が見て思ったことを、混ぜずに並べておきたくて作った。

**事実の誤りが含まれている可能性がある。** 地図や図版もおおよそのもので、正確な地形や境界を示すものではない。
間違いに気づいたら、教えてほしい。直す。

## 構成

`index.html` と、写真を置いた `photo/`、動画（紹介動画 約24秒・音なし、3Dにしたにーみんの約15秒の動き、冒頭の位置図の最後に流す新見の立体地形 約20秒）を置いた `video/` だけ。ビルドは不要で、他所のサーバーへの参照はない
（地図・図版はすべてSVGで、HTMLの中に書いてある）。

冒頭の位置図の県・市の境は、「国土数値情報（行政区域データ）」（国土交通省）を加工して作成した。
位置図の最後に流す立体地形の動画は、国土地理院の標高タイル（10m・5m）を加工して作成した。道路は © OpenStreetMap contributors。
